EPA SeaGrant coral Spectral PreProcessing Results

Preprocessing purpose:

Preprocessing of spectral data is commonly done when attempting to predict chemicals / physiology of an organism using spectroscopy and partial least squares regression. Because of our experimental design, we need a preprocessing method that will help to control for unwanted geometry effects from the probe that happened during time point 1, but can also be used to compare the same fragment imaged through time in the experiment.

Results of preprocessing methods:

The main thing we are looking at here in deciding how to best preprocess the data is how well does the method control for spectral variation in fragments due to unwanted artifacts (in our case, fragment spectra that has higher amplitudes due to inconsistent geometry rather than a biological response, seen especially in time point 1), while still being able to detect and separate out meaningful biological variation?

Method: Mean Centering Normalization

“MCN aligns spectral baselines by subtracting the arithmetic mean of hte dataset from each data point. This method was chosen because of the ability to eliminate baseline shifts, which from looking at the raw data appears to be the main source of unwanted variation in the spectra. This transformation removes global intensity offsets which mitigates spectrometer drift and baseline shifts while retaining relative spectral features - a property critical for PCA where centering ensures principle components reflect true variance rather than artificial offsets.” (Yan, 2025)

Method: Z-score normalizaiton

“ZSN addresses the outlier sensitivity of min-max normalization by standardizing data based on distributional statistics rather than extreme values. This ensures mean-centered, unit-variance distributions while mitigating biases from unknown minima/maxima or singularities (e.g., spectroscopic scatter effects).” (Yan 2025)

# Helper function: reshape spectra, run PCA, and plot scores
run_spectral_pca <- function(data, value_col, dataset_name) {
  
  # Keep coral fragments only; exclude skeleton reference scans
  coral_data <- data %>%
    filter(!str_detect(fragment_ID, "^skeleton_tank")) %>%
    select(
      fragment_ID, site, tank, treatment, timepoint,
      wavelength, value = all_of(value_col)
    )
  
  # Reshape: one row per fragment/timepoint, one column per wavelength
  spectral_wide <- coral_data %>%
    mutate(wavelength = paste0("wl_", wavelength)) %>%
    pivot_wider(
      id_cols = c(
        fragment_ID, site, tank, treatment, timepoint
      ),
      names_from = wavelength,
      values_from = value
    )
  
  # Separate metadata from wavelength variables
  metadata <- spectral_wide %>%
    select(fragment_ID, site, tank, treatment, timepoint)
  
  spectral_matrix <- spectral_wide %>%
    select(starts_with("wl_")) %>%
    as.data.frame()
  
  # Retain observations with complete spectral data
  keep <- complete.cases(spectral_matrix) &
    apply(spectral_matrix, 1, function(x) all(is.finite(x)))
  
  metadata <- metadata[keep, , drop = FALSE]
  spectral_matrix <- spectral_matrix[keep, , drop = FALSE]
  
  # Run PCA: center wavelengths but do not scale each wavelength
  pca <- prcomp(
    spectral_matrix,
    center = TRUE,
    scale. = FALSE
  )
  
  # Calculate variance explained
  variance_explained <- 100 *
    pca$sdev^2 / sum(pca$sdev^2)
  
  # Store PCA scores alongside coral metadata
  scores <- bind_cols(
    metadata,
    as_tibble(pca$x)
  )
  
  # Plot the first two principal components
  # Plot PC1 vs PC2, faceted by treatment
  p <- ggplot(
    scores,
    aes(
      x = PC1,
      y = PC2,
      color = factor(timepoint),
      shape = factor(timepoint)
    )
  ) +
    geom_point(size = 2.5, alpha = 0.8) +
    facet_wrap(~ treatment) +
    labs(
      title = paste("PCA:", dataset_name),
      x = paste0(
        "PC1 (", round(variance_explained[1], 1), "%)"
      ),
      y = paste0(
        "PC2 (", round(variance_explained[2], 1), "%)"
      ),
      color = "Timepoint",
      shape = "Timepoint"
    ) +
    theme_classic(base_size = 13)
  
  print(p)
  
  return(list(
    pca = pca,
    scores = scores,
    plot = p,
    variance_explained = variance_explained,
    n_excluded = sum(!keep)
  ))
}

## Fit a separate linear model for each method ---------------------

pc2_models <- pc2_all %>%
  group_by(method) %>%
  nest() %>%
  mutate(
    model = map(data, ~ lm(PC2 ~ timepoint, data = .x)),
    results = map(model, broom::tidy, conf.int = TRUE),
    fit = map(model, broom::glance)
  )

# Regression coefficients, including slope and confidence interval
pc2_regression_results <- pc2_models %>%
  select(method, results) %>%
  unnest(results) %>%
  filter(term == "timepoint") %>%
  select(
    method,
    slope = estimate,
    std_error = std.error,
    statistic = statistic,
    p_value = p.value,
    conf_low = conf.low,
    conf_high = conf.high
  )

# Model fit statistics
pc2_fit_results <- pc2_models %>%
  select(method, fit) %>%
  unnest(fit) %>%
  select(
    method,
    r_squared = r.squared,
    adj_r_squared = adj.r.squared,
    residual_sd = sigma,
    n = nobs
